# plp-final-project
## 🎶 SongBuddy — AI Song Composition Web App

**SongBuddy** is a MERN full-stack web application designed to help users create original music effortlessly. The platform allows users to write or paste lyrics, select a music genre (such as Hip-Hop, Jazz, Afrobeat, Gospel, etc.), and instantly generate a **melody, chorus, and vocal performance** using **AI-powered music models**.

Whether someone is a songwriter looking for inspiration, a content creator in need of background vocals, or just experimenting with music composition, **SongBuddy makes the creative process simple, fun, and accessible**.

---

### ✨ Key Features

| Feature                      | Description                                                                    |
| ---------------------------- | ------------------------------------------------------------------------------ |
| **Lyrics Assistance**        | Improve or generate lyrics using AI text models.                               |
| **Tune & Melody Generation** | Automatically create instrumental tracks based on the lyrics and chosen genre. |
| **AI Vocals**                | The app generates an electronic voice to sing the lyrics.                      |
| **Song Preview**             | Users can listen to the generated song before purchasing.                      |
| **Payment & Ownership**      | Users can pay to download their custom song and own it.                        |
| **User Accounts**            | Users can save and store their previous songs.                                 |

---

### 🧱 Tech Stack (MERN)

| Layer                        | Technology                                     |
| ---------------------------- | ---------------------------------------------- |
| Frontend                     | **React.js**                                   |
| Backend                      | **Node.js + Express.js**                       |
| Database                     | **MongoDB**                                    |
| AI Lyrics + Music Generation | GPT-5 + MusicGen / Suno API                    |
| Authentication               | JWT (JSON Web Token) / Google Login (optional) |
| Payments                     | M-Pesa STK Push or Stripe                      |

### 💡 Project Goal

The main objective is to **merge music creation with artificial intelligence**, making it possible for anyone—regardless of skill—to compose a professional-sounding song. This project also demonstrates:

* AI integration in real applications
* Full-stack development skills
* Use of authentication, media handling, and payment workflows
* Practical monetization strategies

### 🌍 SDG Alignment — Supporting Youth Employment (SDG 8)

**SongBuddy** contributes to the achievement of **Sustainable Development Goal 8: Decent Work and Economic Growth**, specifically focusing on **youth empowerment and digital entrepreneurship**. The platform enables young creatives to **develop marketable music production skills** and create **original content** that can be monetized. By simplifying the music creation process through AI and providing the option to **download and own generated songs**, SongBuddy helps users produce assets they can share, sell, or use professionally.

#### How SongBuddy Supports SDG 8

* **Promotes entrepreneurship:** Users can create music for their own income-generating projects (e.g., YouTube, TikTok soundtracks, personal albums, advertising jingles).
* **Encourages youth self-employment:** Anyone can produce high-quality music without needing expensive studio access.
* **Builds digital creative skills:** Users learn about songwriting, audio generation, and music structuring.
* **Strengthens the creative gig economy:** Enables users to offer music composition services to others.

This supports **SDG Target 8.3**, which promotes entrepreneurship, creativity, and innovation.
